Add two new computed columns to my stock watchlist dashboard:

Valuation Quality Score (0–100)
Growth Volatility Score (0–100)

These must be fully deterministic calculations (no AI/LLM logic).

Also optionally add a third column:

Combined Opportunity Score (0–100)
-----------------------------
1. VALUATION QUALITY SCORE
-----------------------------

Compute 5 sub-scores (0–20 each):

Growth Score

Growth_Score = min(20, Revenue_YoY_Growth * 0.4)

Valuation Score

If Forward P/E exists:
Valuation_Score = min(20, 200 / Forward_PE)

Else:
Valuation_Score = min(20, 50 / EV_Sales)

PEG Score

PEG = Forward_PE / max(Revenue_YoY_Growth, 1)
PEG_Score = min(20, 20 / PEG)

Margin Score

Margin_Score = (Gross_Margin * 0.1) + (Operating_Margin * 0.2)

Rules:

Add +2 if margins improving YoY
Cap at 20
Minimum 0
Financial Health Score

Start at 20, subtract:

5 if Free_Cash_Flow < 0
5 if Revenue_YoY_Growth < 0
5 if Share_Dilution_YoY > 10%
5 if Debt_to_Equity > 2

Clamp 0–20

Final Valuation Quality Score

Valuation_Quality_Score =
Growth_Score +
Valuation_Score +
PEG_Score +
Margin_Score +
Financial_Health_Score

Clamp 0–100

Label:
80–100 = Undervalued / High Quality Growth
65–79 = Fair Value / Strong Company
50–64 = Neutral
35–49 = Risky / Overvalued
<35 = Weak Fundamentals
-----------------------------
2. GROWTH VOLATILITY SCORE
-----------------------------

Compute 4 sub-scores (0–25 each):

Growth Acceleration Score

Growth_Accel =
(Revenue_YoY_Growth * 0.3) + (Revenue_QoQ_Growth * 0.5)

Growth_Score = min(25, Growth_Accel)

Momentum Score

Momentum_Score =
(15 if Earnings_Revisions_Up else 0)

(5 if Price > 50_day_MA else 0)
(5 if Price > 200_day_MA else 0)

Cap 25

Valuation Efficiency Score

Valuation_Adjusted =
Forward_PE / max(Revenue_YoY_Growth, 1)

Valuation_Score = min(25, 25 / Valuation_Adjusted)

Profitability Optionality Score

Profitability_Score =
(Gross_Margin * 0.2) + (Free_Cash_Flow_Margin * 0.3)

Rules:

+5 if margins improving YoY
Cap at 25
Minimum 0
Final Growth Volatility Score

Growth_Volatility_Score =
Growth_Score +
Momentum_Score +
Valuation_Score +
Profitability_Score

Clamp 0–100

Label:
85–100 = Breakout / Hyper-Growth Leader
70–84 = Strong Uptrend Growth Stock
55–69 = Early / Re-accelerating Growth
40–54 = Stalled / High Risk
<40 = Broken Growth Story
-----------------------------
3. COMBINED OPPORTUNITY SCORE (OPTIONAL)
-----------------------------

This ranks best overall asymmetric opportunities:

Combined_Opportunity_Score =
(0.5 * Growth_Volatility_Score) +
(0.5 * Valuation_Quality_Score)

Clamp 0–100

OUTPUT REQUIREMENTS

For each stock row display:

Valuation Quality Score
Growth Volatility Score
(Optional) Combined Opportunity Score
Both labels

Optional tooltip:

Growth metrics
valuation metrics
momentum signals
margin + financial health breakdown
